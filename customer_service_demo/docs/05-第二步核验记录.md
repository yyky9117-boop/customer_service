## 代表性核对结果

| 场景 | 已核对的期望 |
|---|---|
| 50 元券门槛 | 49.99 元不满足；50.00 和 50.01 元满足 |
| 半分折扣 | 55.05 元的 10% 减免为 5.51 元；两行分摊 2.51 和 3.00 元 |
| 活动后的范围门槛 | 80 元饼干 + 30 元肉类满减后，饼干参与金额 72.73 元，不满足饼干满 75 元券 |
| 百分比券封顶 | 三件 22.90 元谷物棒，20% 减免受 12 元封顶，商品应付 56.70 元 |
| 赠品联合库存 | 买三件同款并赠一件需要四件库存；仅有三件时赠品方案不成立 |
| 优惠后包邮 | 99 元礼盒九折后商品 89.10 元，加 6 元运费，总价 95.10 元 |
| 券可能增加总支出 | 相同 100 元商品，无优惠时包邮共 100 元；只用 2 元券后商品 98 元，加运费共 104 元 |
| 未知运费 | 保留已知商品应付，运费与整单总价为空，不假装确定总价 |
| 赠品非现金 | 买赠不直接扣除赠品标价；六件海苔的每单赠品仍为一件 |
| 零应付非未知 | 抵扣到商品应付为 0 时保留 0，运费仍单独计算 |

“券增加总支出”只比较两个指定候选，并非声称不用任何券是完整优惠集合里的最优方案。实际推荐仍须比较全部合法组合。

## 对通用协议的补充

赠品 `gifts`、约束来源 `origin / derived_from`、预算硬下界 `min_is_hard`、共同预算 `shared_budget` 均为可选补充字段。原有请求与回复示例仍能通过校验。
